# franky-birthday

An interactive phone birthday card for Franky (21 Nov 2026): a day out in York. Single page, `index.html`, no build step. Open until Sat 28 Nov 2026 (the page closes itself after that; `?keep` opens it anyway).

Test switches: `?finale` (light all five candles at once), `?mute`, `?preview` (the 1200x630 link picture), `?expired` (the closed page), `?keep`.
